# Portofolio Naufal (React + Vite + Tailwind)

Jalankan: `npm install` lalu `npm run dev`. Cek lint: `npm run lint`.

Ganti dengan data sendiri:
- Foto profil: `public/images/profil.jpg`
- Foto galeri: `src/assets/gallery/foto1.jpg` s.d. `foto4.jpg` (nama/ekstensi boleh diganti, sesuaikan import di Gallery.jsx)
- Teks & data: array di tiap komponen di `src/components/`
